# Release Tracking

the current release status.

## What each page is for

- The alpha checklist records the historical minimum release gate for `v0.2.0-alpha`.
- The beta support matrix records the current validated desktops, prerequisites, and limits.
- The readiness page summarizes why the repo is or is not release-ready.
- The testing checklist tracks manual, automated, and security coverage.
- The test report captures the most recent verification run and its outcome.

## Current state

UniWamp is in beta release prep. The project currently has passing automation
for the harnessed checks, and the remaining work is focused on release
validation, documentation, and clean-machine confirmation.

For the broader project view, see the main [Home](../index.md) page.
