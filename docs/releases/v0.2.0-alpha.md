# UniWamp v0.2.0-alpha Release Notes

Status: alpha target

UniWamp `v0.2.0-alpha` is the next alpha release line after the initial validation build. It keeps the project focused on local Windows development use and adds the sync and packaging work completed since `v0.1.0-alpha`.

## What Changed

- WinSCP is now a first-class bundled tool in the installer and release manifest.
- Password-auth SFTP now uses bundled PuTTY `psftp.exe` when available, so password-based syncs do not depend on a host-installed tool.
- Sync transport handling is more resilient when WinSCP returns plain directory listings instead of XML output.
- Sync profiles can be cloned from the UI, and the profile editor now preserves selection and save state more reliably.
- Connection tests now report a clearer success or failure state when the remote root directory cannot be confirmed.
- Main window sync buttons now resize and relabel themselves from the active or default sync profiles.
- VHost refresh, shutdown, and metadata write paths were tightened for better state consistency.

## Alpha Scope

- Portable Delphi VCL dashboard for managing a local Apache, MariaDB, and PHP stack.
- Runtime-aware generation of Apache, PHP, MariaDB, vHost, and environment config files.
- Local virtual host management with browser, folder, editor, terminal, delete, and SSL actions.
- PHP runtime selection and PHP extension management.
- Script catalog UI for installing common PHP web applications.
- Terminal-style installation output for script runs.
- Developer tool launchers for local workflow support.
- FTP, FTPS, and SFTP sync connection profiles and sync profiles.

## Required Runtime Files

Unless using a package profile that bundles runtimes, provide these files in the UniWamp tree:

- `runtime/apache/bin/httpd.exe`
- `runtime/mariadb/bin/mariadbd.exe`
- `runtime/mariadb/bin/mysqladmin.exe`
- `runtime/php/<version>/php.exe`
- `runtime/php/<version>/php8apache2_4.dll` or a compatible Apache PHP module

Optional runtime/tool files:

- `runtime/apache/bin/openssl.exe`
- `runtime/nodejs/<version>/...`
- `bin/cmder/Cmder.exe`
- `home/adminer/index.php`

## Known Limitations

- This is still an alpha validation target.
- Clean-machine package validation must be completed before publishing the tag externally.
- Release installers are expected to be signed externally with Authenticode before publication.
- Some script catalog entries depend on upstream installers and may require per-application fixes.
- Runtime folders are intentionally not tracked in Git.
- Generated website project folders under `www/` are intentionally ignored.
- The app is designed for local development workflows only.
